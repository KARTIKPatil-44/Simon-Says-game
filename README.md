# Simon Says Game

This is a simple **Simon Says** game built using HTML, CSS, and JavaScript. The game generates a random sequence of colors, and the player must correctly repeat the sequence by clicking the corresponding buttons.

## Features
- Press any key to start the game.
- A random color sequence is generated for the player to follow.
- The difficulty level increases as the player correctly follows the sequence.
- Visual feedback with flashing colors for game interaction.
- Game over message displayed when an incorrect sequence is entered.

## Technologies Used
- HTML for structuring the web page.
- CSS for styling the buttons and game interface.
- JavaScript for game logic and interaction.

## How to Play
1. Press any key to begin the game.
2. Observe the flashing button indicating the sequence.
3. Click the buttons in the same order as shown.
4. If correct, the game progresses to the next level with an extended sequence.
5. If incorrect, the game displays the score and resets.

## Installation & Running the Game
1. Clone the repository or download the project files.
2. Open `index.html` in a browser to start playing.
3. No additional setup is required.
